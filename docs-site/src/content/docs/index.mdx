<Aside type="note" title="Status">
  v0.2, macOS only, early software. The CLI, the background daemon and the menu-bar app work.
  Linux and Windows are planned, not promised. Expect rough edges and read the
  [Security model](/docs/security/) before you trust it with anything you care about.
</Aside>

grantpin keeps your API keys and database URLs in an encrypted vault on your Mac. An agent such as Claude Code asks to run a command with named secrets. You see the exact command, confirm with Touch ID, and the command runs with the secrets in its environment. The agent only gets the output, with every secret value replaced by `[REDACTED:NAME]`.

No cloud, no account, no analytics. Apache-2.0.
